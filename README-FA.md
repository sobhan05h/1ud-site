# قالب اختصاصی و فوق‌حرفه‌ای `1ud.ir` (معماری بدون بک‌اند / Zero-Backend)

این پروژه یک وب‌سایت کامل، مدرن و فوق‌سریع با **طیف رنگی مشکی خالص، نوارهای آبی تیره و شدوهای نئونی آبی روشن** است که مخصوص دامنه **`1ud.ir`** طراحی شده است.

## ویژگی‌های کلیدی
1. **بدون نیاز به بک‌اند و دیتابیس (هزینه سرور صفر یا حداقل):**
   روی ارزان‌ترین هاست‌های اشتراکی (cPanel / DirectAdmin)، سرورهای استاتیک و حتی سرویس‌های کاملاً رایگان مثل **GitHub Pages**، **Cloudflare Pages**، **Vercel** یا **Netlify** بدون هیچ هزینه‌ای بالا می‌آید.
2. **پنل مدیریت کامل با دستور `/admin`:**
   - **روش اول (آدرس مستقیم):** وارد کردن آدرس `1ud.ir/admin` یا `1ud.ir/#admin` در مرورگر.
   - **روش دوم (دستور کیبوردی):** وقتی داخل صفحه سایت هستید، کافیست روی کیبورد عبارت `/admin` را تایپ کنید (یا کلیدهای `Ctrl + Shift + A` را بزنید) تا پنل مدیریت باز شود!
   - **روش سوم:** کلیک روی دکمه **«پنل /admin»** در هدر بالای سایت.
   - **رمز عبور پیش‌فرض پنل ادمین:** `1234` (قابل تغییر از داخل خود پنل ادمین در تب ۷).

## چطور تغییرات پنل `/admin` را برای همه بازدیدکنندگان دائمی کنیم؟
چون سایت فاقد بک‌اند و دیتابیس است تا هزینه سرور نداشته باشید:
1. وارد `/admin` شوید و اطلاعات خود، عکس پروفایل، پروژه‌ها، مهارت‌ها، سوابق کاری، راه‌های ارتباطی یا حتی طیف رنگی سایت را تغییر دهید.
2. با زدن دکمه **«ذخیره و اعمال آنی»**، تغییرات بلافاصله در مرورگر شما ذخیره و نمایش داده می‌شود.
3. عکس‌های آپلود‌شده (پروژه و آواتار) **فشرده** می‌شوند و هنگام خروجی دائمی به صورت فایل واقعی داخل پوشه **`assets/media`** ذخیره می‌شوند.
4. اگر پروژه‌ای را حذف کنید، عکس مربوط به آن هم در خروجی جدید وجود نخواهد داشت.
5. روی دکمه **«⬇ خروجی دائمی + media»** کلیک کنید تا یک فایل ZIP دانلود شود.
6. محتویات ZIP را روی هاست کپی کنید:
   - `site-data.js` → جایگزین `assets/js/site-data.js`
   - پوشه `assets/media/` → داخل `assets/media/` روی هاست

## ساختار فایل‌ها
- `index.html` : صفحه اصلی پورتفولیو و پروژه‌های 1ud.ir
- `admin/index.html` : مسیر مستقیم `/admin` برای باز شدن پنل مدیریت روی هر نوع وب‌سرور
- `assets/css/style.css` : استایل‌های اختصاصی مشکی، نوارهای آبی تیره و شدوهای آبی روشن نئونی
- `assets/js/site-data.js` : بانک اطلاعاتی استاتیک سایت (بدون نیاز به دیتابیس)
- `assets/js/app.js` : موتور رندرینگ، فیلتر پروژه‌ها و مهارت‌ها و تشخیص دستور `/admin`
- `assets/js/admin.js` : سیستم مدیریت محتوای کامل `/admin`
- `assets/media/` : پوشه ذخیره عکس‌های آپلود‌شده پروژه‌ها و آواتار (پس از خروجی دائمی)
- `.htaccess` : تنظیمات مسیریابی و فشرده‌سازی سرعت برای هاست‌های لینوکسی
